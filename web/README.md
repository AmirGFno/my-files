# روبیک‌باز — پلتفرم وب آموزش روبیک

سایت استاتیک، بدون build step و بدون وابستگی بیرونی. فقط `index.html` را باز کن
(یا برای تست محلی: `python3 -m http.server 8000`).

## ساختار

```
web/
├── index.html          پوسته‌ی اپ (topbar، main، footer)
├── css/app.css         توکن‌های طراحی + کامپوننت‌ها (تم روشن/تیره)
├── js/cube-engine.js   مدل مکعب + رندر سه‌بعدی تعاملی (Canvas، بدون کتابخانه)
├── js/app.js           روتر هش + ویوها
├── data/methods.js     محتوا: پازل → روش → گام → شش بخش ثابت
└── fonts/              Vazirmatn (woff2، خودمیزبان)
```

## مسیرها

| مسیر | صفحه |
|---|---|
| `#/` | خانه و فهرست پازل‌ها |
| `#/p/3x3` | روش‌های یک پازل |
| `#/learn/3x3/lbl` | معرفی یک روش + فهرست گام‌ها |
| `#/learn/3x3/lbl/cross` | یک گام (قالب شش‌بخشی) |
| `#/algs` | جست‌وجوی همه‌ی الگوریتم‌ها |

## چطور محتوا اضافه می‌شود

فقط `data/methods.js` را ویرایش کن — هیچ کد جاوااسکریپتی لازم نیست:

```js
{
  id: 'new-step',
  title: 'نام گام',
  goal: 'در پایان این گام چه چیزی حل شده است.',
  why: 'منطق پشت روش.',
  states: [{ label: 'قبل', alg: '', view: 'default' },
           { label: 'بعد', alg: "R U R' U'", view: 'top' }],
  steps: [{ t: 'قدم اول', d: 'توضیح' }],
  algorithms: [{ alg: "F R U R' U' F'", label: 'توضیح کوتاه' }],
  mistakes: ['خطای رایج و راه خروج'],
  alternatives: [{ name: 'تکنیک دیگر', why: 'چرا بهتر است', moves: '۸',
                   difficulty: 3, ref: 'other-step-id', recommended: true }],
}
```

`view` یکی از `default | top | bottom | back` است. وضعیت مکعب از `alg` شبیه‌سازی
می‌شود، پس اگر الگوریتم غلط باشد تصویر هم غلط درمی‌آید و فوراً دیده می‌شود.

## تست‌ها

```bash
node --check js/app.js && node --check js/cube-engine.js
node /tmp/t.js              # تست‌های منطق مکعب (sexy×۶، x⁴، T-perm×۲، دیزی، صلیب)
cd /tmp/domtest && node test.js   # رندر همه‌ی مسیرها با jsdom
```

## وضعیت محتوا

- **۳×۳ / لایه‌به‌لایه**: ۷ گام کامل (هدف، چرا، قدم‌ها، الگوریتم، خطاها، جایگزین‌ها)
- **۳×۳ / پتروس، ZZ، CFOP**: اسکلت گام‌ها آماده، متن در نوبت
- **۲×۲**: لایه‌به‌لایه، اورتگا، CLL — در برنامه
- **بقیه‌ی پازل‌ها**: فقط کارت معرفی

## ایده‌های بعدی

- ذخیره‌ی پیشرفت هر گام در `localStorage`
- حالت تمرین: الگوریتم را از حافظه بزن و اپ درستی‌اش را چک کند
- تایمر و شمارش حرکت برای هر روش
- استاتیک‌سازی همین محتوا به PDF (موتور چاپ در `book/tools` موجود است)
