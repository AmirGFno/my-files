# پرونده‌های تحویلِ فصل دوم

سه فایل، برای دو ایجنتِ بیرونی.

## ۱ — ویراستارِ ادبی

| فایل | چه وقت استفاده شود |
|---|---|
| `03-prompt-for-literary-editor.txt` | **پرامپتِ خالی**، با جای متن. اگر می‌خواهی متن را جدا یا تکه‌تکه بفرستی. |
| `01-text-for-literary-editor.txt` | **آمادهٔ ارسال**، پرامپت + متنِ کاملِ فصل. اگر می‌خواهی یک فایل بدهی و کار تمام. |

هر دو یک محتوا دارند؛ تفاوت فقط در این است که یکی جای متن را خالی گذاشته.

خروجیِ خواسته‌شده از ویراستار یک فایلِ UTF-8 است با این دو بخش:

```
=== متن ویرایش‌شده ===
(متنِ کاملِ جایگزین)

=== گزارش ویرایش ===
(حداکثر ۳۰ خط)
```

فایلِ برگشتی را بده تا جایگزین `chapter-02.md` کنم و بیلد بگیرم.

## ۲ — پژوهشگرِ تصویر

| فایل | چیست |
|---|---|
| `02-prompt-for-image-researcher.md` | پرامپتِ کاملِ چهار تصویرِ H02، H47، H48، H03 |

خروجیِ خواسته‌شده، چهار خط با این قالب:

```
ID|filename|direct-url|source-page|creator|date|license|WxH
```

ردیف‌ها را در `book/images/historical-requests.txt` بگذار و ورک‌فلوی
`upload-historical.yml` را روی همین شاخه اجرا کن؛ فایل‌ها در
`book/images/historical/` می‌نشینند و با یک بیلدِ تازه سرِ جایشان می‌روند.
