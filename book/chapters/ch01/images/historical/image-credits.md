## ข้อกำหนดการใช้งาน

- **CC BY-SA 4.0** (H01, H46): ต้องแสดงเครดิตผู้สร้าง ระบุลิขสิทธิ์ และอนุญาตให้ดัดแปลงภายใต้สัญญาอนุญาตเดียวกัน (ShareAlike) เหมาะสำหรับหนังสือ PDF/DOCX หากปฏิบัติตามเงื่อนไข
- **สาธารณสมบัติ / Public Domain** (H45): ไม่ต้องแสดงเครดิตบังคับ แต่แนะนำให้ระบุแหล่งที่มา (British Library / IDP) เพื่อความโปร่งใส
- **Watermark**: ห้ามใช้ภาพที่มีลายน้ำเชิงพาณิชย์ ห้ามลบลายเซ็นหรือหมายเลขทะเบียนโบราณวัตถุออกจากภาพต้นฉบับ
- **ขนาดภาพ**: H01 และ H46 ผ่านเกณฑ์ความกว้างขั้นต่ำ 2400 พิกเซล; H45 กว้าง 2128 พิกเซล ต่ำกว่าเกณฑ์ขั้นต่ำแต่สูงกว่า 1600 พิกเซล ยอมรับได้กับเหตุผลที่บันทึกไว้ในรายงาน

## หมายเหตุสำคัญ

ไม่มีไฟล์รูปภาพใดถูกดาวน์โหลดในสภาพแวดล้อม sandbox เนื่องจาก `upload.wikimedia.org` ถูกบล็อกจากระบบเครือข่าย (SSL_ERROR_SYSCALL / HTTP 000) และ `fetch_page` คืนค่า HTTP 500 สำหรับ URL รูปภาพโดยตรง ดังนั้นทุกรหัสจึงมีสถานะ `failed_download` และต้องดาวน์โหลดด้วยตนเองจากเครื่องที่มีการเชื่อมต่ออินเทอร์เน็ตเต็มรูปแบบ โดยใช้ `image_file_url` ใน `image-manifest.csv`

หลังดาวน์โหลดแล้ว ให้ตรวจสอบรูปแบบไฟล์ ขนาดพิกเซล และขนาดไฟล์จากตัวไฟล์จริง ก่อนถือว่าเป็น “downloaded_verified_locally”
