# فصل ۱ — مقدمه؛ راز چرخهٔ بزرگ زمان

وضعیت: **نوشته، صفحه‌آرایی و آمادهٔ بازبینی** — در انتظار تأیید کاربر برای رفتن به فصل ۲.

نسخهٔ فعلی، بازبینی‌شده بر پایهٔ درخواست کاربر: **بدون باکس شناسنامه، بدون زیرنویس تصویر، بدون یادداشت‌های ویرایشی داخل روایت**؛ تصویرها کوچک و **شناور لای متن با wrap** هستند.

## فایل‌های تحویل

| فایل | توضیح |
| --- | --- |
| `build/chapter-01-fa.pdf` | نسخهٔ صفحه‌آرایی‌شده، A4، راست‌چین، ۱۳ صفحه، شمارهٔ صفحهٔ فارسی، بوک‌مارک بخش‌ها |
| `build/chapter-01-fa.docx` | نسخهٔ ویرایش‌پذیر Word؛ تصویرها با **Tight wrap** شناور شده‌اند |
| `build/image-credits.md` | اعتبارات تصاویر — **بیرون از روایت**؛ در منابعِ پایانِ کتاب ادغام می‌شود |
| `chapter-01.md` | منبع متنی فصل (تک‌منبعِ حقیقت برای هر دو خروجی) |
| `chapter-image-manifest.csv` / `.json` | شناسنامهٔ پنج تصویر: وضعیت، جایگاه، پهنا، منبع، مجوز |

فونت: **Vazirmatn** (مجوز OFL) در `book/assets/fonts/`. برای دیدن درست DOCX، این فونت باید روی سیستم نصب باشد.

## چه چیزهایی از روایت حذف شد

- **باکس شناسنامهٔ اول فصل** (`:::meta`) — چاپ نمی‌شود. محتوایش (باران، سنگ، نور چراغ، حلقهٔ دوازده دروازه، کتابِ بسته با هالهٔ بی‌نشان) از قبل در پاراگراف‌های آغازین بافته شده بود؛ جملهٔ کلیدیِ «زمان دو چهره دارد» حالا در دیالوگِ راهنما، پایان بخش شش، گفته می‌شود.
- **زیرنویس و توضیح عکس‌ها** — هیچ زیرنویسی چاپ نمی‌شود. اطلاعات ضروری به دیالوگ منتقل شد: نامِ موزهٔ باستانیِ ملیِ آتن برای H01، و برای H46 اینکه تصویر وضعیتِ امروزیِ ساعت است نه ساختهٔ صنعتگرِ اول.
- **صفحهٔ اعتبارات و یادداشت پایانی** — از PDF و DOCX بیرون رفت و در `build/image-credits.md` نشست.
- بلوک‌های `:::meta`، `:::note`، `:::credits` و `:::internal` در هیچ خروجی‌ای چاپ نمی‌شوند.

**جدول دوازده عصر نگه داشته شد**، چون داخل داستان اتفاق می‌افتد (راهنما آن را روی هوا می‌نشاند) و بازه‌های زمانیِ کتاب را حمل می‌کند. اگر این هم مزاحم روایت دانسته شود، حذفش یک خط تغییر در اسکریپت است.

## ساخت دوبارهٔ خروجی‌ها

```bash
python3 -m venv .venv
.venv/bin/pip install pillow python-docx reportlab arabic-reshaper python-bidi
.venv/bin/python book/tools/build_chapter.py book/chapters/ch01
```

اسکریپت `chapter-01.md` را می‌خواند، مشتق‌های چاپی را در `images/print/` می‌سازد (بازتولیدشدنی، در گیت نادیده گرفته شده) و PDF و DOCX و فایل اعتبارات را تولید می‌کند.

نکته: H01 و H46 در این چک‌اوت روی دیسک نیستند مگر اینکه از `origin/main` بازیابی شوند:

```bash
git fetch origin main
git show origin/main:book/images/historical/H01_CH01_antikythera-mechanism.jpg > book/images/historical/H01_CH01_antikythera-mechanism.jpg
git show origin/main:book/images/historical/H46_CH01_prague-orloj-dial.jpg  > book/images/historical/H46_CH01_prague-orloj-dial.jpg
```

### ساختار منبع متن

- `# ` عنوان فصل، `## ` عنوان بخش، `> ` دیالوگ راهنما، `---` شکست صحنه
- `:::figure id=… placement=opener|float-left|float-right|inline width=…mm` — **بدنهٔ این بلوک توضیحِ منبع است و چاپ نمی‌شود**
- `:::table id=ages` جدول اعصار (تنها عنصر غیررواییِ چاپ‌شدنی)
- `:::meta` / `:::note` / `:::credits` / `:::internal` — چاپ نمی‌شوند

## کنترل کیفیت انجام‌شده

- ۱۵۶ بلوک روایی؛ ۱۵۵ بلوک با تطبیق برنامه‌ای در متنِ استخراج‌شدهٔ PDF پیدا شد. یک بلوک به‌خاطر ابهامِ کدپوینتِ الف در نقشهٔ ToUnicodeِ فونتِ جاسازی‌شده تطبیق نشد، اما به‌صورت تصویری روی صفحهٔ ۱۱ تأیید شد.
- **صفر هم‌پوشانی متن و تصویر**: مختصات هر span متنی با مستطیل هر تصویر مقایسه شد.
- تنها لاتینِ چاپ‌شده در کل PDF، نامِ دوازده برج در جدول است — یعنی هیچ زیرنویس، شناسه یا اعتباری داخل روایت نمانده.
- DOCX: چهار `wp:anchor` با `wrapTight` (چپ/راست/راست/چپ) و یک تصویر inline برای آغاز فصل؛ ترتیب عناصر و چندضلعیِ wrap معتبر است.
- صفحات ۲، ۵، ۶، ۷، ۸، ۱۰، ۱۱ و ۱۳ به‌صورت تصویری بازبینی شدند.
- **محدودیت شناخته‌شده:** کپی‌کردنِ متن از PDF نیم‌فاصله‌ها و گاهی کدپوینتِ الف را جابه‌جا می‌کند (نتیجهٔ شکل‌دهیِ دستیِ حروف). برای ویرایش و جست‌وجو از DOCX یا `chapter-01.md` استفاده کنید.
