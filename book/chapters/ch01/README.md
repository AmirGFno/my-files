# بسته تصویری فصل ۱

فصل ۱: **مقدمه؛ راز چرخه بزرگ زمان**

## تصویرهای اختصاصی

دو تصویر اختصاصی این فصل آماده است:

- `images/originals/A02_ch01_opener.jpg` — تصویر آغاز فصل: ورود مسافر و دیدار با راهنما.
- `images/originals/A17_ch01_inner.jpg` — تصویر داخلی فصل: گفت‌وگوی خاموش مسافر و راهنما در برابر دروازه‌ها.

این فایل‌ها تصویرسازی تولیدشده‌اند، نه سند تاریخی. نسخه اصلی سراسری آن‌ها در `book/images/originals/` نیز نگه داشته می‌شود.

## تصویرهای تاریخی

سه تصویر تاریخی این فصل هنوز باید توسط ایجنت جست‌وجو دانلود و برای بررسی قرار گیرد:

- `H01` — سازوکار آنتیکیترا
- `H45` — نقشه ستارگان دونهوانگ
- `H46` — ساعت نجومی پراگ

پوشه تحویل:

`book/chapters/ch01/images/historical/`

پرامپت آماده کپی برای ایجنت:

`book/chapters/ch01/historical-image-search-prompt.md`

## فهرست ماشین‌خوان

`chapter-image-manifest.csv` و `chapter-image-manifest.json` وضعیت هر پنج تصویر فصل را نگه می‌دارند. تا وقتی فایل‌های تاریخی دانلود و بررسی نشده‌اند، وضعیت آن‌ها `pending_agent_download` است.
