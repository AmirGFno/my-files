# کتاب آموزش حل مکعب روبیک — جلد اول

نمونه‌ی اولیه (Sample) برای تأیید سبک، ساختار و موتور تصویرسازی.

فایل خروجی: `out/sample-pages.pdf` — سه صفحه‌ی نمونه:

1. **نقشه راه** — صفحه‌ی معرفی، چهار روش ۳×۳، نت‌نویسی
2. **یک گام آموزش** — دیزی/صلیب سفید: دو حالت سه‌بعدی + نمای تخت + الگوریتم + «چرا کار می‌کند» + جدول مقایسه
3. **کارگاه روش‌های جایگزین** — سه گام، سه جایگزین برای هر گام، با ارجاع به صفحه‌ی توضیح کامل

## اجرا

```bash
cd book/tools
python3 sample.py        # -> ../out/sample-pages.pdf
```

پیش‌نیاز: `pip install reportlab arabic-reshaper python-bidi fonttools`
(برای پیش‌نمایش تصویری: `pillow pypdfium2`)

## ساختار کد

| فایل | کار |
|---|---|
| `cube3d.py` | موتور واقعی مکعب ۳×۳: وضعیت هر استیکر، ضرب ماتریس چرخش، پارس نت‌نویسی (`R U R' U2 …`). هیچ تصویری «نقاشی» نیست؛ همه از وضعیت شبیه‌سازی‌شده ساخته می‌شود |
| `render.py` | رندر وکتور: دوربین اورتوگرافیک، حذف وجه پشتی، سایه، هایلایت؛ خروجی PDF و SVG از یک منبع هندسی + نقشه‌ی تخت وجه ۳×۳ |
| `rtl.py` | الگوریتم دوجهته + شکل‌دهی حروف فارسی؛ الگوریتم‌ها (مثل `(R U R' U')`) به‌صورت یک واحد LTR حفظ می‌شوند |
| `typo.py` | لایه‌ی تایپوگرافی: شکستن سطر، تراز راست، اعداد فارسی، فاصله‌گذاری الگوریتم‌ها |
| `design.py` | سیستم طراحی: صفحه، رنگ‌بندی سطح‌ها (مبتدی/متوسط/حرفه‌ای)، کارت، کال‌اوت، جدول |
| `scenes.py` | وضعیت‌های مکعب مورد استفاده، هر کدام با تست ویژگی (مثلاً «دیزی واقعاً دیزی است؟») |
| `sample.py` | همین سه صفحه |

فونت: Vazirmatn (SIL Open Font License) در `fonts/`.

## تست‌های صحت

```
R U R' U' × ۶ = مکعب حل‌شده      ✅
T-perm × ۲   = مکعب حل‌شده      ✅
x × ۴        = مکعب حل‌شده      ✅
شبکه‌ی «دیزی»: مرکز زرد + چهار لبه‌ی سفید رو به بالا، چهار گوشه زرد   ✅
```

## تصمیم‌های قفل‌شده

- جلد اول: **۳×۳ و ۲×۲** — فعلاً تمرکز روی ۳×۳
- ۳×۳ با **۴ روش**: لایه‌به‌لایه (مبتدی) · پتروس (متوسط) · ZZ (متوسط) · CFOP (حرفه‌ای)
- «روش جایگزین» = **چند تکنیک برای همان مرحله**، نه روش کامل دیگر
- توضیح کامل جایگزین‌ها: **یک بخش واحد** در پایان بخش ۳×۳
- هر ارجاع «← ص ۲۲» با **شناسه‌ی یکتا** ساخته می‌شود و شماره‌ی صفحه در زمان ساخت تزریق می‌شود (هیچ شماره‌ای دستی تایپ نمی‌شود)
- تصاویر: رندر واقع‌گرا برای شروع فصل + دیاگرام تخت وکتور برای مراحل
