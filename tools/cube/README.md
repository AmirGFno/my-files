# tools/cube — ابزارهای صحت‌سنجی مکعب

این اسکریپت‌ها بدون مرورگر اجرا می‌شوند و همان کدی را می‌آزمایند که سایت
استفاده می‌کند (`web/js/cube-engine.js`, `web/data/methods.js`).

| فایل | کار |
|---|---|
| `gen.js` | وضعیت همه‌ی گام‌های ۳×۳ لایه‌به‌لایه را می‌سازد و هر ادعا را می‌سنجد (شکل درست است؟ کار گام‌های قبل سالم مانده؟ الگوریتم به وضعیت بعدی می‌رسد؟). خروجی `scenes.json`. |
| `viewtest.js` | تست رندر: ۲۷ استیکر، چرخش واقعی لایه در میانه‌ی انیمیشن، زوایای دوربین، سرعت. |
| `geom.js` | سهم هر وجه در هر زاویه‌ی دوربین + بررسی نبود هم‌پوشانی استیکرها. |
| `shot.js` | رندر PNG بدون مرورگر (رستری‌ساز کوچک) برای بازبینی چشمی. |
| `scenes-shot.js` | یک شیت از همه‌ی شکل‌های گام‌ها، تا با هم دیده شوند. |
| `strip.js` | شش فریم از یک حرکت (`node strip.js R`) برای دیدن اینکه لایه واقعاً می‌چرخد. |
| `algcheck.js` | متن صفحه و انیمیشن را با هم می‌سنجد: الگوریتم چاپ‌شده باید همان حرکتی باشد که شکل اجرا می‌کند. |
| `datacheck.js` | لینت محتوا: شناسه‌ی تکراری، گام ناقص، الگوریتم خالی، لینک جایگزینِ مرده. |

```bash
node tools/cube/gen.js
node tools/cube/viewtest.js
node tools/cube/geom.js
node tools/cube/datacheck.js
node tools/cube/algcheck.js
node tools/cube/scenes-shot.js   # → tools/cube/out/scenes-sheet.png
```

خروجی PNGها در `tools/cube/out/` ساخته می‌شود و نباید کامیت شود.
