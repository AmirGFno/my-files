# tools/dom — تست‌های DOM با jsdom

این تست‌ها به `jsdom` نیاز دارند (وابستگی توسعه، نه وابستگی سایت):

```bash
npm install jsdom
node tools/dom/routes.test.js   # همه‌ی مسیرها + کنترل‌های شکل + مودال بزرگ
node tools/dom/move.test.js     # شمارنده‌ی زنده‌ی حرکت‌ها و پایان انیمیشن
```

`routes.test.js` بدون خطا از همه‌ی مسیرها رد می‌شود و `move.test.js` باید هر دو
خط OK را چاپ کند. تست دوم طول می‌کشد (چند ثانیه) چون واقعاً یک الگوریتم هفت‌حرکتی
را تا آخر پخش می‌کند.
