# پوشه تصاویر تاریخی/مستند H01 تا H78

این پوشه فقط فایل‌های تاریخی یا مستند را نگه می‌دارد. تصویرسازی‌های اختصاصی در `book/images/originals/` هستند و نباید با این مسیر مخلوط شوند.

## وضعیت فعلی

- فایل موجود: `H72_CH08_earthrise-apollo-8.jpg`
- ابعاد واقعی: 1280×1280 پیکسل.
- وضعیت: کم‌کیفیت، نیازمند جایگزینی با نسخه با وضوح بالا و تأیید منبع اصلی.
- فایل با یک آینه GitHub تطبیق هش دارد، اما اصل NASA و مجوز/شرایط استفاده هنوز مستقلاً تأیید نشده است.
- ۷۷ شناسه دیگر H فایل محلی ندارند.

## داده‌های خام و بررسی‌شده

- `image-manifest.csv` و `image-manifest.json` در ریشه پروژه: خروجی خام ایجنت قبلی؛ شامل ادعاها، لینک‌های ناقص و برخی ستون‌های جابه‌جا.
- `book/review/image-source-audit.csv` و `.json`: بررسی محلی/ساختاری هر شناسه، وضعیت فایل، شکل لینک، ابعاد واقعی در صورت وجود، و کسری‌ها.
- `book/review/remaining-assets.csv`: فهرست اقدام‌های باقی‌مانده.
- `book/image-audit.md`: گزارش فارسی اصلاح‌شده.

## قاعده استفاده

لینک صفحه منبع به معنی دسترسی به فایل تصویر نیست. برای هر شناسه باید فایل واقعی دریافت شود، باز شود، ابعاد و فرمت از خود فایل خوانده شود، موضوع با کاتالوگ تطبیق یابد، و مجوز/انتساب تأیید شود. هیچ تصویر تولیدشده با هوش مصنوعی جایگزین اثر تاریخی نشود.
